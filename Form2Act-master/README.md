# Form2Act — протоколы, акты, дипломы

Веб-приложение на **Python** и **Flask**: данные из Excel и Google Forms → Word-шаблоны с полями `{имя}` и **MERGEFIELD**. Склонение ФИО (родительный падеж), конструктор шаблонов, предпросмотр, сводные акты со списком в таблице.

## Возможности

- Слияние источников (ДП, опрос, ГИА, шаблоны) по ФИО
- Протокол на студента или **zip** на группу
- **Сводный акт**: один `.docx`, таблица на N строк (шаблон с таблицей)
- Выбор источника строк таблицы: база студентов, таблица с вкладки «Дипломы», загруженный `.xlsx`
- Конструктор и предпросмотр `.docx` в браузере
- Вкладка «Дипломы» — отдельные Excel-таблицы для форм

## Быстрый старт

```bash
git clone <репозиторий>
cd Form2Act
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
./run.sh
```

Откройте **http://127.0.0.1:5000** (другой порт: `PORT=5001 ./run.sh`).

## Где что лежит

| Путь | Содержимое |
|------|------------|
| **`data/`** | Основные Excel (ДП, опрос, ГИА, шаблоны) и **Word-шаблоны** `.docx` |
| **`uploads/diploma_tables/`** | Таблицы с вкладки «Дипломы» (отдельно от data/) |
| **`uploads/table_data/`** | Excel, загруженные только для акта/шаблона со списком |
| **`output/`** | Сгенерированные документы |

Типичные файлы в `data/`: `ДП …xlsx`, `Проба1(данные).xlsx`, `ГИА_результаты …xlsx`, `шаблоны для дипломов …xlsx`, `протоколШАБЛОН ….docx`, `Акт …_merge.docx`.

## Вкладки интерфейса

| Вкладка | Задача |
|---------|--------|
| **Протоколы** | Загрузка данных, выбор шаблона, студенты, скачивание |
| **Дипломы** | Excel-таблицы (можно использовать как источник строк для акта) |
| **Предпросмотр** | Документ + поля одного студента |
| **Конструктор** | Редактирование шаблона, вставка `{полей}` |

## Протокол (один студент)

1. Положите `.docx` и `.xlsx` в `data/`, нажмите **Перезагрузить из data/**.
2. Выберите шаблон протокола.
3. Отметьте студента → **Скачать**.

## Акт со списком в таблице

1. Шаблон с полями в **одной строке** таблицы (`…_merge.docx` или `{Фамилия_имя_отчество}`, `{Группа}`, `{n_pp}` в конструкторе).
2. Под шаблоном Word появится блок **«Строки таблицы»** — можно отметить **несколько источников сразу** (объединятся в один список):
   - отмеченные студенты (база из `data/`);
   - одна или несколько таблиц с вкладки «Дипломы»;
   - один или несколько загруженных `.xlsx` для шаблона.
3. **Скачать акт** — один файл.

Удалить таблицу «Дипломы 26.05.2026»: вкладка **Дипломы** → выбрать → **Удалить таблицу**.

Шапка акта (дата, количество…) — из полей **первого** отмеченного студента или правок в редакторе.

## Поля шаблона

| Поле | Смысл |
|------|--------|
| `F2` | ФИО в родительном падеже |
| `Фамилия_имя_отчество` | ФИО именительный |
| `Группа`, `группа_год` | Группа / год набора |
| `Темы_дипломного_проекта`, `Руководитель`, `Вопросы` | Из ДП и опроса |
| `Протокол`, `Дата_защиты_диплома`, `оценкаДиплом`, `ГИА` | Из ГИА и шаблонов |

Полный список: `form2act/config.py` → `MERGE_FIELDS`.

## Частые проблемы

**Нет модуля flask** — `.venv/bin/pip install -r requirements.txt` и `./run.sh`.

**Порт занят** — `PORT=5001 ./run.sh`.

**Конструктор «ломается» после смены шаблона** — **Сбросить правки** в конструкторе или **Обновить** в предпросмотре (Ctrl+F5).

**Лист Excel не найден** — выберите вкладку в настройках или исправьте имя листа.
